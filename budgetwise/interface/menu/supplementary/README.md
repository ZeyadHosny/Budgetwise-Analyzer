# interface/menu/supplementary

| File | Task | Feeds |
|---|---|---|
| `menu_flow.md` | `P1.5` | report — **design flow diagram** |

§5 requires *"design flow diagram based on important subroutines"*. The menu is
where every path through the program begins, so this is the natural backbone of
that diagram.

Record each option, what it calls, and what comes back. Keep it current — a flow
diagram that no longer matches the program is worse than none, and a grader can
check it against the code in seconds.
