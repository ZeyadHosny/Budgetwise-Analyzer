# pipeline/supplementary

| File | Purpose | Feeds |
|---|---|---|
| `integration_notes.md` | What broke when the modules first met, and how it was fixed | report — implementation details |
| `interface_conflicts.md` | Where two modules disagreed on a type or name, and what was agreed | `G1`, report — design decisions |

`G2` is the first moment five people's code runs together. Write down what
went wrong while it is fresh — it is the most honest material the report will
have, and "limitations and future work" is a required section.
