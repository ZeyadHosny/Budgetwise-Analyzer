## Rules

- **Time it properly.** 20 minutes is a hard limit, and it includes Q&A.
- **Everyone speaks**, in the order and for the time agreed in `outline.md`.
- **Everyone answers at least one mock question** — `P6.1`'s own requirement.
- **Run the live demo on the real machine.** Not a laptop that will not be there.

## Rehearsal 1 checklist — P6.1

- [ ] Total time under 20 minutes including Q&A
- [ ] Every member spoke
- [ ] Speaking time roughly even — §7 grades this
- [ ] Demo ran without intervention
- [ ] Every member answered a mock question
- [ ] Action list written from what went wrong

## Rehearsal 2 checklist — P6.3

- [ ] Every action from rehearsal 1 addressed
- [ ] Timing confirmed a second time
- [ ] Slides final — no edits after this point
- [ ] Demo rehearsed on the presentation machine
- [ ] Screen recording saved as a fallback
- [ ] Submission checklist signed off

## Common failures, worth avoiding

| Problem | Fix |
|---|---|
| Overrunning | Cut slides, not speaking pace |
| One person speaking most of it | Re-split; the criterion is explicit |
| Live demo fails | Fallback recording, rehearsed machine |
| A question lands on the wrong person | Everyone learns the whole pipeline |
| Slides unreadable from the back | Bigger type, fewer words |
